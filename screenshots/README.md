# Demonstration Screenshots

Run the program from the repository root:

```bash
g++ -std=c++17 -O2 -Wall -Wextra src/safe_planner.cpp -o safe_planner
./safe_planner
```

For the final demonstration, capture the terminal output showing the six test cases and place the screenshots in this folder.

Suggested filenames:

- `test1_reachability.png`
- `test2_bad_state_avoidance.png`
- `test3_safety_margin.png`
- `test4_dynamic_transition.png`
- `test5_goal_update.png`
- `test6_transition_addition.png`
